# @select-box/vue

Vue 3 wrapper for the select-box library.

Part of [select-box](https://github.com/giovani-freitag/select-box) — one framework-agnostic core, with thin wrappers for
React, Vue, Lit, Web Components and jQuery. Same snapshot fields, same keyboard
behaviour, same ARIA wiring, whichever wrapper renders it.

```bash
npm install @select-box/vue @select-box/core
```
