Add a `group` key on each option. Options sharing the same key bundle under
that header, and options without a `group` fall under whatever `ungroupedLabel`
you pass.

<Demo />

## How filtering interacts with groups

When the user types, every group's options are filtered independently. Groups
that end up empty drop out of the rendered list — the user only sees headers
that still have at least one match. Keyboard navigation skips empty groups
and disabled options automatically.
