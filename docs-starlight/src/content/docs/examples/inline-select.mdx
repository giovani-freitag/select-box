Set `surface` to `"inline"` and every option lands on the page as a chip — no
popover, no input, no search. Right when the set is small and worth showing at
once.

<Demo />

## When to reach for it

Filter pills, role pickers, segmented controls, small tag editors —
anywhere seeing every choice at a glance beats a dropdown. For long
lists, async data, or anything that benefits from search, the default
popover surface is still the right tool.

## Cardinality stays independent

`surface` decides how the options are painted; `multiple` decides what a
click does to the selection. Switching surfaces never touches the
selection itself, so `single + inline` reads as a radio-style chip
group (click replaces) and `multi + inline` as a toggle group (click
flips each). `onChange` follows `multiple`, not `surface`.

The framework switcher above shows the exact opt-in for each wrapper —
a single prop, attribute, or option on the same `<SelectBox>` that
drives the popover variant.
