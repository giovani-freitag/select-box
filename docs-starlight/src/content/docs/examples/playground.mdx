## What just happened

Surface, selection, options and state all changed on a **live instance** — the
component never remounted, because those are the things the controller can
change at runtime. Flipping to multiple keeps whatever was already picked, the way
the browser does when a `<select>` gains `multiple`.

Addons are the exception: they attach when the controller is built, so changing
that set rebuilds the preview.
