A flat array of `{ value, label }` is enough. No groups, no extras.

<FrameworkDemo scenario="simple">
    <Fragment slot="react-code">
        ```tsx
        import { SelectBox } from "@select-box/react";
        import { useState } from "react";

        const fruits = [
            { value: "apple", label: "Apple" },
            { value: "pear", label: "Pear" },
            { value: "grape", label: "Grape" },
            { value: "lemon", label: "Lemon" },
            { value: "peach", label: "Peach" },
        ];

        export function FruitPicker() {
            const [value, setValue] = useState<string | null>(null);
            return (
                <SelectBox
                    options={fruits}
                    placeholder="Pick a fruit"
                    onChange={(next) => setValue(next)}
                />
            );
        }
        ```
    </Fragment>

## What you get for free

- Case-insensitive **and diacritic-insensitive** substring search out of the box
  (typing `sao` matches `São`).
- Full keyboard navigation: `↓` / `↑` to move, `Enter` to commit, `Escape` to close.
- ARIA combobox semantics — no extra wiring needed for screen readers.
- The list is rendered through a virtualizer (see [Large list](/examples/large-list/)),
  so even small datasets like this one stay snappy.
