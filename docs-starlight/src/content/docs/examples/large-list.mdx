## How it stays fast

- **Only visible rows are in the DOM.** A 240 px popover with 36 px rows keeps
  ~7 nodes live at any moment, regardless of the source array's size.
- **The filter walks the array linearly.** For hundreds of thousands of short
  strings, that's tens of milliseconds per keystroke — no throttling needed.
- **Keyboard nav scrolls into view in O(1).** Moving past the visible window
  jumps directly to the target offset, no DOM diffing.
