The default filter is `SubstringFilterStrategy` — case- and diacritic-insensitive
substring match. Pass any other strategy via the `filter` prop to change how
matches are computed.

## Set a filter once

`@select-box/addon-fuzzy` exports `FuzzyFilterStrategy`, which tolerates typos
and gaps via `fuse.js`. Pass it as `filter` and you're done.

<StaticDemo />

## Swap the filter at runtime

The filter prop is reactive. Hand the controller a new strategy via
`setFilter(strategy)` — or rebind the React/Vue prop — and the open popover
re-filters in place. No remount, no state loss.

<SwapDemo />

## Lock fuzzy on with an addon

To enable fuzzy permanently without managing the strategy yourself, register
`FuzzyAddon`:

```ts
import { FuzzyAddon } from "@select-box/addon-fuzzy";

<SelectBox options={fruits} addons={[new FuzzyAddon({ threshold: 0.3 })]} />;
```

The addon calls `setFilter` at attach time and restores the previous filter on
detach.
