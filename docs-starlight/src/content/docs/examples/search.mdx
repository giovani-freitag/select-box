## Default — substring matching

Typing in the trigger filters the list with a case- and diacritic-insensitive
substring match. No setup beyond the `options` prop.

<DefaultDemo />

## Fuzzy via `FuzzyAddon`

Install [`@select-box/addon-fuzzy`](../../guides/addons/) and register `FuzzyAddon` to tolerate
typos and out-of-order characters via `fuse.js`.
