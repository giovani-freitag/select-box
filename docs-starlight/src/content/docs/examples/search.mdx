The default filter is `SubstringFilterStrategy` — case- and diacritic-insensitive
substring match. Install [`@select-box/addon-fuzzy`](/api/) and pass
`FuzzyFilterStrategy` to tolerate typos and gaps via `fuse.js`. The filter is
swappable at runtime via `controller.setFilter(strategy)` — no remount, no
state loss.

<Demo>
    <Fragment slot="react-code">
        ```tsx
        import { useState } from "react";
        import { SelectBox } from "@select-box/react";
        import { FuzzyFilterStrategy } from "@select-box/addon-fuzzy";
        import { SubstringFilterStrategy, type OptionFilterStrategy } from "@select-box/core";

        const SUBSTRING = new SubstringFilterStrategy();
        const FUZZY = new FuzzyFilterStrategy();

        export function FruitSearch() {
            const [filter, setFilter] = useState<OptionFilterStrategy>(SUBSTRING);
            return (
                <>
                    <label>
                        <input
                            type="checkbox"
                            onChange={(event) => setFilter(event.target.checked ? FUZZY : SUBSTRING)}
                        />
                        Use fuzzy search
                    </label>
                    <SelectBox options={fruits} filter={filter} placeholder="Search fruits…" />
                </>
            );
        }
        ```
    </Fragment>

## Lock fuzzy on with an addon

To enable fuzzy permanently (no toggle), pass `FuzzyAddon` instead of swapping
the strategy by hand:

```ts
import { FuzzyAddon } from "@select-box/addon-fuzzy";

<SelectBox options={fruits} addons={[new FuzzyAddon({ threshold: 0.3 })]} />;
```

The addon calls `setFilter` at attach time and restores the previous filter on
detach.
