The default filter is `SubstringFilterStrategy` — case- and diacritic-insensitive
substring match. Install [`@select-box/addon-fuzzy`](/api/) and pass
`FuzzyFilterStrategy` instead to tolerate typos and gaps via `fuse.js`.

Toggle the switch and watch every framework swap filters at runtime through
the same `controller.setFilter()` call. Try queries like:

- `aple` — only fuzzy finds **Apple**, **Pineapple**, **Loquat**, etc.
- `mng` — only fuzzy finds **Mango**, **Tangerine**.
- `berry` — both match, but fuzzy ranks by score (best first).

## How the swap works under the hood

Every wrapper calls `controller.setFilter(newStrategy)` on the same core
controller. The controller rebuilds `filteredGroups` against the current
query, publishes a fresh snapshot, and every subscriber (the wrapper's
render, the search input, the popover) reacts. **No remount.** Custom CSS
or scroll positions stay intact.

For pages that want fuzzy on permanently, plug the `FuzzyAddon` instead of
swapping by hand:

```ts
import { FuzzyAddon } from "@select-box/addon-fuzzy";

<SelectBox options={fruits} addons={[new FuzzyAddon({ threshold: 0.3 })]} />;
```

`FuzzyAddon` is just a thin wrapper that calls `host.setFilter(new FuzzyFilterStrategy(config))` at attach time and restores the previous strategy on detach.
