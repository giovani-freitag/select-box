import ReactDemo from "../../../components/demos/hoist-selected/ReactDemo.tsx";

Install [`@select-box/addon-hoist-selected`](../../guides/addons/) and the currently selected
option is lifted into a synthetic top-most group whenever the popover renders —
the user always sees their choice first.

This page wires React only; the addon is framework-agnostic and behaves the same
in all five. The [playground](../playground/) turns it on next to the others.
