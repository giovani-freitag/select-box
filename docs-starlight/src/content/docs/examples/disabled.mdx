Set `disabled: true` on an option to keep it visible but uncommittable. When
every option in a group is disabled, the group itself is marked `disabled` in
the snapshot and keyboard navigation skips the whole block. The shipped
stylesheet does not dim the header — read `group.disabled` and style it if you
want that.

<Demo />

## What "disabled" guarantees

- **Pointer clicks are ignored.** Hovering still highlights the row, but the
  controller's commit method short-circuits on disabled options.
- **Keyboard nav skips them.** `↓` / `↑` find the next enabled option in either
  direction; `Enter` on a disabled active option is a no-op.
- **Filtering still matches them.** A disabled row that matches the query stays
  visible (dimmed) — users can see *why* a value is unavailable rather than
  wondering whether they spelled it wrong.
- **A disabled option is refused even to the owner.** `setValue` and the
  initial value both drop it: setting a disabled option leaves the selection
  empty, and setting a list keeps only the enabled entries. Disabling an option
  is a statement about the value, not only about the row — so restoring a
  persisted selection whose option has since been disabled restores nothing.
  Keep the option enabled if the value has to survive.
